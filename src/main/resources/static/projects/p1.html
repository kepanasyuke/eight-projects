REST API по контракту

CRUD по OpenAPI-контракту: наружу уходят только DTO, вход проверяется Jakarta Validation, а изменяющие запросы защищены ключом идемпотентности.

Проект 01 p1.svg

Что реализовано

  • DTO отделены от сущности — WorkItemRequest и WorkItemResponse описывают контракт, JPA-сущность WorkItem наружу не выходит.
  • Валидация на входе — @Valid на теле запроса: длина заголовка, приоритет 1..5, обязательный исполнитель. Дополнительно сервис проверяет допустимость команд.
  • Идемпотентное создание — Заголовок Idempotency-Key сохраняет результат операции в таблицу idempotency_record; уникальность ключа держит база, а не приложение.
  • Пагинация и фильтрация — PageResponse отдаёт items, page, size и totalElements, фильтр по статусу применяется в запросе.
  • Ошибки как данные — ApiError с кодом и деталями, GlobalExceptionHandler переводит исключения в согласованные HTTP-статусы.

Живые вызовы

Фрагмент кода

                    
                

                
@PostMapping
public ResponseEntity<WorkItemResponse> create(@RequestHeader("Idempotency-Key") String idempotencyKey,
                                               @Valid @RequestBody WorkItemRequest request) {
    WorkItemResponse created = this.idempotency.execute(idempotencyKey, CREATE_OPERATION,
            WorkItemResponse.class, () -> this.service.create(request));
    ResponseEntity<WorkItemResponse> response = ResponseEntity.status(HttpStatus.CREATED).body(created);
    return response;
}

            

            

                
Как читать результат

                
Нажмите «Создать» дважды с одним и тем же ключом: второй вызов вернёт сохранённый ответ и не создаст дубликат. Смените ключ в атрибуте data-headers, чтобы получить новую запись.

                
Полный список эндпоинтов проекта доступен на витрине:
                    /api/showcase/projects.

                
Проект запускается профилем по умолчанию на H2 в режиме PostgreSQL; профиль
                    postgres переключает приложение на настоящий PostgreSQL из
                    docker-compose.yml.
