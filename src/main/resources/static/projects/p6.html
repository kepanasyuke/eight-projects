XML, XSD и защита от XXE

Счёт по схеме с include общей библиотеки типов: сборка через JAXB, валидация через SchemaFactory и разбор, которому запрещены DTD и внешние сущности.

Что реализовано

  • Схема как контракт — invoice.xsd включает common-types.xsd: типы InvoiceNumber, Inn, Money и структуры Party/InvoiceItem описаны один раз и переиспользуются.
  • JAXB с явным пространством имён — Все поля модели помечены namespace = urn:eight:invoice, иначе при elementFormDefault=qualified элементы уезжают в пустое пространство и валидация падает.
  • Валидация с разбором ошибок — ErrorHandler собирает предупреждения и ошибки с номерами строк, отчёт возвращается клиенту списком.
  • Закрытые внешние ресурсы — SchemaFactory: ACCESS_EXTERNAL_DTD пуст, ACCESS_EXTERNAL_SCHEMA ограничен file,jar. XMLInputFactory: SUPPORT_DTD=false, IS_SUPPORTING_EXTERNAL_ENTITIES=false.
  • Сборка и разбор в одном месте — build формирует документ и сразу валидирует его, parse возвращает разобранную модель с итогом.

Фрагмент кода

                    
                

                
private static Schema loadSchema() {
    Schema schema = null;
    try {
        SchemaFactory factory = SchemaFactory.newInstance(XMLConstants.W3C_XML_SCHEMA_NS_URI);
        factory.setProperty(XMLConstants.ACCESS_EXTERNAL_DTD, "");
        factory.setProperty(XMLConstants.ACCESS_EXTERNAL_SCHEMA, "file,jar");
        URL resource = XmlService.class.getResource(XSD_PATH);
        schema = factory.newSchema(resource);
    } catch (SAXException ex) {
        throw new IllegalStateException("Схема " + XSD_PATH + " не загружена", ex);
    }
    return schema;
}
